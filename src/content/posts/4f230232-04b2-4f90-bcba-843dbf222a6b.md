파이썬에서 두 변수에 각각 수를 입력받을 때 일반적으로 많이 쓰이는 방법이다.
```
a, b = map(int, input().split())
```

```
a, b = tuple(map(int, input().split()))
```

```Tuple``` 을 사용하나 안하나 별 차이는 없이 잘 작동한다.

# 차이점
작동 상의 차이점은 없다. 그러나 의미 상의 차이점이 있다.
```Map``` 의 경우에도 ```Tuple``` 과 같이 Unpacking을 지원하기 때문에 잘 작동한다.

다만, 보통 ```Map``` 은 사용시 ```List``` 나 ```Tuple``` 과 같이 원하는 형태로 형변환을 진행한 이후에 사용하게 되는 경우가 자주 있기에 
가독성 측면에서 정확히 2개의 값으로 떨어지는 ```Tuple``` 을 만들어 이를 ```Unpacking``` 한다는 의미를 줄 수 있다.
