## 최대공약수
> ### 유클리드 호제법을 이용
두 수 ```a```, ```b``` (```a``` > ```b```)가 있을 때,
``` 
GCD(a, b) = GCD(b, a%b)
```
```b```가 ```0```이 되면, 그때의 ```a```가 최대공약수

```javascript
const gcd = (a, b) => {
  if (b === 0) return a;
  return gcd(b, a%b);
};
```

## 최대공배수
> ### 최대공약수의 방법을 이용
```
LCD(a, b) = (a * b) / GCD(a, b)
```

```javascript
const lcm = (a, b) => {
  return (a * b) / gcd(a, b);
};
```
