> # 경로 
- 파일 시스템에서 파일이나 디렉토리의 위치를 저장하는 문자열
>
> - 절대경로와 상대경로는 위치의 지정 방법

# 절대경로

- 항상 루트(`/`)에서부터 시작
- 파일 또는 폴더의 위치를 시스템 전체에서 한 번에 특정
- 예시
  - `/home/user/doc.txt`
- 특징
  - 경로가 어디서 쓰이든 변하지 않음
  - 어디서 실행하든 항상 같은 파일 또는 폴더를 참조

# 상대경로

- **현재 작업 중인 디렉토리(현재 위치)**를 기준으로 파일/폴더의 위치를 지정
- 두 가지 특수기호
  - `.`: 현재 디렉토리 (e.g. `./boostcamp.txt`)
  - `..`: 상위(부모) 디렉토리 (e.g. `../readme.txt`)
- 예시
  - `docs/report.txt`
    - 현재 위치의 하위 docs 폴더 속 report.txt
  - `../data/file.csv`
    - 상위 폴더의 data 폴더 내부 file.csv
- 특징
  - 프로그램의 `현재 위치`에 따라 의미가 달라짐
