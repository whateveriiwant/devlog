문제: 자리수의 합계를 계산하는 프로그램을 재귀를 이용해 작성
예) 123의 경우 6이 출력됨 

```
#include <stdio.h>

int get_digit_sum(int n) {
    if (n / 10 != 0) {
        return (n % 10) + get_digit_sum(n / 10);
    }
    return n;
}

int main() {
    int num;
    printf("정수를 입력하시오: ");
    scanf("%d", &num);

    printf("%d", get_digit_sum(num));
}
```
