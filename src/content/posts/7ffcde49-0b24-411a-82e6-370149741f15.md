1부터 n까지의 합(1+2+3+4+...+n)을 Recursion 활용해 구하는 문제

```
#include <stdio.h>

int sum(int n) {
    if(n != 0) {
        return n + sum(n-1);
    }
    else {
        return n;
    }
}

int main() {
    int num;
    printf("정수를 입력하시오: ");
    scanf("%d", &num);

    printf("1부터 %d까지의 합 = %d", num, sum(num));
}
```
